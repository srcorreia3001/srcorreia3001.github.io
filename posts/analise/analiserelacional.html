Análise Relacional e Consultas SQL para Negócios

22 de Julho, 2026 • 4 min de leitura

Sobre o Projeto...

Desenvolvi esse projeto focado em SQL(Structured Query Language) utilizando um ambiente corporativo simulado via SQlite no Kaggle.O objetivo foi transformar dados brutos em inteligência comercial através de consultas estruturadas, cobrindo desde os filtros fundamentais até agregação financeiras complexas.

Desenvolvimento do projeto

  • Arquitetura e carga:Importação de dados transacionais e criação e um banco de dados relaiconal local (SQlite) utilizando Python como ponte de integração.
  • Inspeção de Esquema:Utilização de comandos de metadados (PRAGMA table_info) para validar estruturas e os tipos de dados das colunas.
  • Consultas Básicas:(SELECT, WHERE, ORDER BT): Filtragens de registros de alto valor e ordenação de maiores faturamentos e lucros por cliente.
  • Agregação Comercial (GROUP BY, SUM): Agrupamento estratégico de dados para calcular o faturamento total e o lucro acumulado por categoria de produto.

Principais Insights

  • A categoria Technology destacou-se com o maior volume de faturamento agregado na base
  • o uso de funções de agregação permitiu uma visão gerencial imediata, provando a eficiência de estruturar dados em bancos relacionais.

Tecnologias Utilizadas:

  • Python e SQlite(Gerenciamento e conexão de banco de dados
  • Pandas (Exibição e manipulação de DataFrames)
  • SQL(Consultas, filtros e agregações
  • Kaggle Notebooks (Ambiente de desenvolvimento)
